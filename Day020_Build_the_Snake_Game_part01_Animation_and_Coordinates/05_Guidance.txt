Well, the point is that programming is not about memorizing because we're in a day and age where information
is cheap. You can search Google for any piece of information you want and it's there within a second.
What your job needs to be is to understand how things work. Make sure that you understand how to use
the code, when to use it, how it works behind the scenes. That way, the next time when you need to use it 
and you've forgotten how to write the syntax, you can just Google it, look it up. And as soon as you see it, 
you'll remember "Oh yeah, that's it. I know how to use it." So don't worry about memorizing things. 
Focus on understanding the code.
